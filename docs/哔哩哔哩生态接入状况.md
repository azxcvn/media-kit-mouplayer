### 已完成内容

1. **基础设施**

     Android 走 EncryptedSharedPreferences/Keystore，对齐小喵 player 方案）两个依赖。
   - `lib/services/bilibili/bili_constants.dart`：域名 / 固定 UA / Referer / TV appkey·appsec / 扫码状态码。
   - `lib/services/bilibili/bili_api.dart`：端点常量（集中式，对齐 PiliPlus `api.dart`）。
   - `lib/utils/bili_wbi.dart`：WBI 签名纯函数（`biliGetMixinKey` / `biliEncWbi`，
     混淆表以 bilibili-API-collect / Bili23 的 64 项表为准，官方示例向量已验证）。
   - `lib/services/bilibili/bili_http.dart`：统一请求封装（Cookie/UA/Referer/buvid3 注入 +
     UTF-8 解码 + 错误语义化 `BiliApiException`）。

2. **凭证安全存储**
   - `lib/services/bilibili/bili_credential_store.dart`：SESSDATA / bili_jct / DedeUserID +
     access_token / refresh_token 加密存储；`BiliCredential` 提供 Cookie 解析（cookie_info.cookies
     的 `fromCookies` / 浏览器复制 Cookie 的 `parse` 两种来源）。

3. **扫码登录（对齐 PiliPlus 的 TV 通道）**
   - `lib/utils/bili_app_sign.dart`：TV 端 appSign（appkey/appsec MD5，对齐 PiliPlus）。
   - `lib/services/bilibili/bili_auth_service.dart`：TV 扫码生成/轮询（`mobi_app=android_hd` + appSign，
     请求头 `app-key: android64` + `x-bili-aurora-zone: sh001`，对齐 PiliPlus `getHDcode`/`codePoll`
     实际发出的 `Constants.baseHeaders`；凭证直接 JSON 返回 token_info + cookie_info，
     **不依赖 Set-Cookie**）/ nav 自检 / buvid 预取 / 退出登录。
   - `lib/pages/bilibili/bili_login_page.dart`：扫码页（二维码 + 状态提示 + 180 秒倒计时自动刷新）
     + Cookie 导入页（粘贴解析兜底）。
   - 扫码页三个操作：**刷新二维码** / **保存到相册**（RepaintBoundary 截图 + `saver_gallery`）/
     **打开哔哩哔哩**（`bilibili://browser` 深链直接 `startActivity`，未装抛异常提示未安装）。
   - 原生侧：`MainActivity.kt` 新增 `openBilibiliScan`；`AndroidManifest.xml` 新增 `bilibili://` 的 `<queries>` 声明。

4. **登录态管理与入口**
   - `lib/services/bilibili/bili_account.dart`（ChangeNotifier 单例）：登录态 / 用户信息 /
     WBI 密钥缓存 / buvid；启动 `ensureLoaded` 读凭证 + nav 自检（Cookie 过期静默清凭证）。

### 已知待办 / 风险（阶段一遗留）

- **TV 通道风险**：扫码登录已用 TV 通道（android_hd 第三方 appkey，灰色地带），PiliPlus 在设置里
  明示风险；本项目后续可在设置页加醒目提示。
- **反爬指纹是精简版**：当前只做 buvid3 预取 + 固定 UA + Referer。Bili23 的完整反爬
  （buvid_fp / b_lsid / b_nut / bili_ticket via GenWebTicket / ExClimbWuzhi）未接入——
  这些主要影响 **playurl 取流**（阶段三），若届时遇 412 风控再补。
- **Cookie 过期提示**：nav 自检发现过期目前是「静默清凭证回游客态」，未做「非阻塞提示重新扫码」。
- **退出登录**调用了 `/login/exit/v2` 但未严格验证其返回（本地清凭证为准）。
- **国际版扫码登录未解决**：国际版哔哩哔哩客户端（`com.bilibili.app.in`，`android_i`，走 biliintl
  独立账号体系）扫 TV 二维码后无法完成确认，轮询始终停在「未确认」（日志 `86090 已扫码` → 退回
  `86039`，拿不到 `code=0`）。已尝试对齐 PiliPlus 请求头（`app-key: android64`），仍未解决；
  彻底解法是改走 **Web 扫码**（`/x/passport-login/web/qrcode/generate` + `poll`，老项目小喵 player
  验证过的跨客户端通用方案），代价是拿不到 TV access_token、仅 Web 画质（1080P）。

## 阶段三：番剧播放（播放 / 弹幕 / 画质 / 章节）✅ 已完成

### 已完成内容

1. **playurl 解析**（`lib/models/bili_dash.dart` + `lib/services/bilibili/bili_video_service.dart`）
   - PGC `/pgc/player/web/v2/playurl`（`result.video_info`）+ UGC `/x/player/wbi/playurl`（`data`），
     `fnval=4048` + `fourk=1` + WBI 签名；DASH 流兼容 `baseUrl`/`base_url`/`baseUrls[]` 双格式。
   - bvid→cid（`/x/web-interface/view`）；错误码友好提示（-404/-403/-10403/-352/87008）。

2. **B 站原声弹幕**（`lib/services/bilibili/pb/pb_reader.dart` + `bili_danmaku_service.dart`）
   - REST 分段 protobuf：`/x/v2/dm/web/view`（分段数 `dmSge.total`）→ `/x/v2/dm/web/seg.so`
     （`elems`），手写 wire 解码（字段号对齐 PiliPlus `v1.pb.dart`），`progress`(ms)→秒、
     `color`→RGB、跨分段按 id 去重、按时间升序；失败降级 `comment.bilibili.com/{cid}.xml`（deflate）。
   - 缓存落盘 `filesDir/danmaku/bilibili/{cid}.xml`（标准 B 站 XML，复用 `parseDanmakuXml`）。

3. **mbedTLS 绕过（本地流代理）**（`lib/services/bilibili/bili_stream_proxy.dart`）
   - 排查确认自编 `libmpv.so` 静态链接 mbedTLS（与小喵 player 同源，B 站 CDN TLS 兼容风险）。
   - 纯 Dart 本地 HTTP 代理：`HttpClient`（BoringSSL）出站拉流 + `HttpServer` 127.0.0.1 明文喂
     mpv，转发 Range；播放结束 `dispose` 释放端口。根治方案（内核重编 OpenSSL）见 ARCHITECTURE §4.15。

4. **播放器集成**（`lib/models/bili_media.dart` + `player_page.dart` + `views/player_quality_panel.dart`）
   - `BiliMedia` 值对象：当前画质 DASH 流 + cid/aid + clips + `switchQuality` 回调。
   - `PlayerPage` 新增 `biliMedia`：双流播放（video + `audio-add` 外挂音轨，`openAndRestore`
     新增 `beforePlay` 钩子）、B 站弹幕装载、OP/ED 章节喂入、更多面板「清晰度」入口。
   - 清晰度面板：列出 `accept_quality`，当前档高亮，切换重开 + seek 保持进度（默认请求最高档 qn=127）。
   - OP/ED 章节：playurl `clip_info_list`（`CLIP_TYPE_OP/ED`）→ `ChapterInfo` + `SkipSegment`
     喂入 `ChapterTracker.setExternalChapters`。

5. **入口接线**（`lib/pages/bilibili/bili_play_launcher.dart`）
   - 番剧详情 / 全屏选集 / BV 链接三处统一走 `playBiliEpisode`/`playBiliBvid`（解析中模态进度 →
     失败 toast → 成功进播放页）。
